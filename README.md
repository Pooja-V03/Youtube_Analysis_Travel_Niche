# Indian Travel YouTube — Niche Analysis

An end-to-end data pipeline and exploratory data analysis on the Indian travel-vlogging niche on YouTube — 419 channels, 718 videos, collected via the YouTube Data API v3 and analyzed with industry-level statistical validation.

## 🎯 What this project answers

- Does video length actually affect engagement — and do Shorts outperform long-form?
- Does upload frequency correlate with subscriber growth?
- Is there a "best" time or day to post travel content in India?
- Do specific title keywords (budget, solo, backpacking, hidden, guide, tips, best) move the needle on views/engagement?
- How does channel size (Large/Mid/Small tier) interact with all of the above?

Every question is answered with a code cell + statistical test (ANOVA, Pearson/Spearman correlation, t-tests) followed by a written conclusion — not just charts.
